# NVR SFU 会议（实验功能）

在配置文件中启用 `sfu.enabled: true`，并使用内嵌媒体引擎，重启 NVR 后访问 `/sfu-meet/`。使用 NVR 超级管理员账号入会，浏览器采集摄像头、麦克风或屏幕需要安全上下文（HTTPS 或 localhost）及相应权限。WebSocket 使用一次性短期入会凭证；配置文件密码不会放入信令 URL。

当前实现仅提供一个内存房间，采用 Opus 和 H.264；会议视频轨道可手动桥接到 lal Group，通过页面内 WHEP 预览。桥接会在源结束或授权失效时停止，重启后不自动恢复。服务会保留历史桥接输出身份，以防重启后误将旧身份当成普通未保护流。

目前未配置 STUN/TURN，连接依赖浏览器能够直接访问服务端 ICE 地址；跨 NAT、弱网、扩容、自动重连、音视频同步及生产环境容量仍待验证。媒体引擎实例被替换时，会议服务会关闭，需重启 NVR 后恢复。不要把实验功能视为已完成 Issue #93 的全部验收。
