# SFU 分批实施计划

跟踪：[Issue #93](https://github.com/lalmax-pro/lalmax-nvr/issues/93)。首版架构与延期边界见 [P0 首版决策](sfu-p0-decisions.md)；每批独立验证并在 Issue 记录，勾选不代表生产验收。

1. **Room、轨道与控制**：内存房间、generation、限额、轨道、订阅、快照和事件流已实现；NVR 已接入多房间管理和可选空闲回收。恢复凭证与自动重连仍待实施。
2. **纯 SFU 链路**：WebSocket 授权控制、Pion 媒体绑定、有界 RTP 分发、H.264/Opus 双向收发和关键帧反馈已接入；完整重传、拥塞和弱网策略待实施。
3. **GroupBridge**：音频、视频及同一成员音视频组合可桥接到独立 Group，NVR 提供授权、管理和 WHEP 播放；长期同步、录像、异常网络和生产容量待验收。
4. **Meet Demo**：本地独立演示与 NVR 页面支持设备、屏幕视频、动态订阅和桥接；NVR 支持房间管理。实际公网、设备矩阵和人工听音待验收。
5. **稳定性与质量**：持续实施细粒度授权、断线恢复、完整 RTCP/拥塞控制、TURN、公网、容量与资源泄漏验证；再评估摄像头 Group 到 SFU 的适配。
