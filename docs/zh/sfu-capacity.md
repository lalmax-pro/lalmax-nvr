# LiveKit SFU 本机容量基线

2026-11-09 在 Apple M3（8 逻辑核、16 GiB 内存）、macOS 15.5、Go 1.26.8 上测量。LiveKit 服务端运行在独立进程，发布者和观看端运行在测试进程；所有连接均为本机回环。

每组持续 15 秒，一个发布者以约 30 个 RTP 包/秒发送 H.264 合成数据，每个观看端订阅同一轨道。测试数据用于测量转发，不是可用于画面质量评估的真实编码视频；未启用音频、桥接、录像或转码。

| 观看端 | 发布包/秒 | 接收包/秒合计 | 接收 RTP 载荷合计 | 首个 RTP 包耗时范围 | 服务端 CPU 采样均值 | 服务端 RSS 采样最大值 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 30.0 | 30.0 | 0.223 Mbit/s | 201 ms | 1.1% | 53.8 MiB |
| 4 | 30.0 | 120.1 | 0.893 Mbit/s | 163–201 ms | 1.5% | 61.6 MiB |
| 7 | 30.0 | 210.0 | 1.561 Mbit/s | 161–202 ms | 1.7% | 70.9 MiB |

CPU 和 RSS 由 `ps` 每秒采样，CPU 百分比以单核为 100%；macOS 的 CPU 值是衰减平均值。服务端进程包含 Go 测试框架但不包含测试客户端实例；三组按顺序复用同一个服务端进程，后续 RSS 和 CPU 采样可能受前一组影响。载荷速率不含 RTP、UDP、IP、重传和信令开销；首包耗时从观看端开始连接计时，不是浏览器解码首帧耗时。该结果不代表公网性能、生产容量或长期稳定性。

复现：

```sh
SFU_CAPACITY_TEST=1 SFU_CAPACITY_DURATION=15s go test -timeout 4m -tags livekit_capacity ./internal/livekitsfu -run '^TestLiveKitCapacityBaseline$' -count=1 -v
```

测试使用 `ps` 采样，适用于 macOS 和常见 Linux 环境；实际资源占用与硬件、编码、码率、网络、房间配置和观看端行为有关。
