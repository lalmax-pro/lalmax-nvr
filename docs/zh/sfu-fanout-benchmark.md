# SFU RTP fanout 微基准

该基准测量单个发布源向若干订阅队列复制并交付 RTP 包的进程内开销。每次写入一包后立即同步排空所有队列，包载荷为 1200 字节；不包含 WebRTC 加解密、网络、丢包、浏览器、桥接、录像或慢消费者。`deliveries/s` 是写入包数乘订阅数除以计时，表示队列交付次数，并非实际网络包速率或可支持的会议人数。

复现：

```sh
cd third/lalmax
go test ./sfu/rtpforward -run '^$' -bench '^BenchmarkFanout$' -benchtime=1s -count=3
```

2026-11-08 本机运行记录：Apple M3、16 GiB 内存、macOS arm64、Go 1.26.2，默认 `GOMAXPROCS=8`。这是非隔离机器的三次结果范围，机器负载、Go 版本和参数均会影响结果，不应用作生产容量承诺。

| 1 | 686–990 ns | 101 万–146 万 | 1424 B，2 次 |

待补充真实端到端负载：并发房间/发布/订阅、编码与码率、包速率、CPU、内存、网络出口、慢端与丢包、首帧延迟及长时间运行。应在目标部署环境记录具体硬件、网络拓扑和测试工具，不能将本基准的队列交付次数换算为实际出口带宽。
